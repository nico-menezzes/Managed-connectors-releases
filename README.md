# Managed Connectors

Instaladores do **Managed Connectors**, app gratuito para Mac e Windows que liga o Claude a várias contas Webflow ao mesmo tempo.

Baixe a [última versão](https://github.com/nico-menezzes/managed-connectors-releases/releases/latest):

- **Mac com chip Apple (M1 ou mais novo):** `mac-arm64.dmg`
- **Mac Intel:** `mac-x64.dmg`

O app não é assinado: no Mac, clique com o botão direito e escolha **Abrir** na primeira vez.

Este repositório guarda só os instaladores e o `latest.json` que o app usa para avisar de versão nova.
